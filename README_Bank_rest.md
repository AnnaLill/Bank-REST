#  Система Управления Банковскими Картами

Это backend-приложение для управления банковскими картами, разработанное на Spring Boot. Приложение предоставляет RESTful API для создания карт, управления ими и перевода средств между картами.

##  Основные возможности

-   **Аутентификация пользователей**: Безопасная аутентификация на основе JWT с ролями (`USER`, `ADMIN`).
-   **Управление картами**: Администраторы могут выполнять полный набор CRUD-операций над любой картой.
-   **Пользовательский сервис**: Пользователи могут просматривать свои карты, запрашивать блокировку и переводить средства между своими счетами.
-   **Безопасность**: Номера карт шифруются в базе данных и маскируются в ответах API. Доступ ко всем эндпоинтам контролируется на основе ролей.
-   **Миграции базы данных**: Схема БД управляется с помощью Liquibase.
-   **Документация API**: API полностью документировано с использованием Swagger/OpenAPI.
-   **Контейнеризация**: Приложение готово к развертыванию в Docker.

##  Начало работы

### Необходимые условия

-   Java 17 или новее
-   Maven 3.6+
-   Установленные Docker и Docker Compose

### 1. Настройка приложения

Откройте файл `src/main/resources/application.yml` и при необходимости обновите следующие разделы:

-   **База данных**: Укажите ваши имя пользователя и пароль для PostgreSQL. Значения по умолчанию: `postgres`/`postgres`.
-   **Секрет JWT**: Установите надежный, закодированный в Base64 секрет для `app.jwt.secret`.
-   **Ключ шифрования**: Установите надежный 16/24/32-байтный ключ для `app.encryption.key` для шифрования AES.

### 2. Запуск базы данных

Проект включает файл `docker-compose.yml` для быстрого запуска базы данных PostgreSQL в Docker-контейнере.

```bash
docker-compose up -d
```

Эта команда запустит контейнер PostgreSQL с базой данных `bank_card_system_db`.

### 3. Запуск приложения

#### Вариант 1: Запуск через IDE или Maven

Вы можете запустить приложение через вашу IDE или с помощью Maven-обертки:

```bash
./mvnw spring-boot:run
```

#### Вариант 2: Запуск через Docker

1. Соберите JAR файл:
```bash
./mvnw clean package
```

2. Соберите Docker образ:
```bash
docker build -t bank-card-system .
```

3. Запустите контейнер:
```bash
docker run -p 8080:8080 --name bank-card-app bank-card-system
```

Приложение будет доступно по адресу `http://localhost:8080`.

##  Документация API

После запуска приложения вы можете получить доступ к интерактивной документации API (Swagger UI) по адресу:

**[http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui/index.html)**

API защищено. Для доступа к защищенным эндпоинтам вы должны сначала аутентифицироваться через эндпоинт `/api/auth/login`, чтобы получить JWT-токен, а затем использовать кнопку "Authorize" в Swagger для его применения.

### Пользователи по умолчанию

Два пользователя создаются по умолчанию с помощью миграций Liquibase:

-   **Имя пользователя**: `admin`
-   **Пароль**: `admin`
-   **Роль**: `ADMIN`

-   **Имя пользователя**: `user`
-   **Пароль**: `user`
-   **Роль**: `USER`

##  Краткий обзор API Endpoints

### Аутентификация (`/api/auth`)

-   `POST /login`: Аутентификация и получение JWT-токена.

### Управление картами (Администратор) (`/api/v1/admin/cards`)

-   `GET /`: Получить постраничный список всех карт.
-   `POST /`: Создать новую карту для пользователя.
-   `GET /{id}`: Получить карту по ее ID.
-   `PATCH /{id}/status`: Обновить статус карты.
-   `DELETE /{id}`: Удалить карту.

### Управление картами (Пользователь) (`/api/v1/user/cards`)

-   `GET /`: Получить постраничный список карт аутентифицированного пользователя.
-   `PATCH /{id}/block`: Заблокировать одну из своих карт.

### Управление переводами (`/api/v1/user/transfers`)

-   `POST /internal`: Перевести средства между своими картами.
