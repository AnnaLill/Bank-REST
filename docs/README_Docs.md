# Документация API

В этой директории находится вся сгенерированная документация для API.

## `openapi.yaml`

Это основной файл спецификации API, соответствующий стандарту **OpenAPI 3.0**. Он содержит полное, формальное и машиночитаемое описание всех доступных эндпоинтов, их параметров, моделей данных (DTO) и возможных ответов.

### Генерация файла

Файл `openapi.yaml` не редактируется вручную. Он **генерируется автоматически** из аннотаций в исходном коде контроллеров (`@Operation`, `@ApiResponse` и т.д.) с помощью `springdoc-openapi-maven-plugin`.

Для обновления этого файла необходимо:
1. Запустить приложение.
2. В отдельном терминале выполнить команду:
   ```bash
   ./mvnw springdoc-openapi:generate
   ```
Это гарантирует, что документация всегда на 100% соответствует реальному коду.

## Интерактивная документация (Swagger UI)

Для удобного просмотра и тестирования API используйте **Swagger UI**, который доступен по адресу (когда приложение запущено):

[http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui/index.html)

### Авторизация в Swagger UI

Все защищенные эндпоинты требуют JWT-авторизации. Чтобы получить доступ:
1. Выполните запрос `POST /api/auth/login`, чтобы получить токен.
2. Нажмите на кнопку **"Authorize"** в правом верхнем углу интерфейса.
3. Вставьте полученный токен в формате `Bearer {ваш_токен}`.
